# Portfólio · Richard de Assis Marques

Site de página única (HTML, CSS e JavaScript puros). Abre com duplo clique no `index.html`.

## Estrutura

```
index.html
css/style.css
js/main.js
assets/favicon.svg
assets/img/foto-richard.jpg / .webp
```

## O que ainda falta preencher

Procure por `TROCAR` no `index.html`:

- **Formspree:** crie um formulário em https://formspree.io e troque `SEU_ID` na tag `<form>`.
- **Currículo:** coloque o PDF em `assets/curriculo-richard-marques.pdf`.
- **Imagem de compartilhamento:** `assets/img/og-image.png` (1200×630).
- **Telefone:** confirmar o número (celular costuma ter 9 dígitos).
- **Orbe:** adicionar o link "Ver online" com a URL do Render.
- **Percentuais** das barras de habilidades (opcional).

## Publicar na Vercel

1. Crie o repositório `portfolio` no GitHub e envie estes arquivos.
2. Em https://vercel.com, "Add New Project", importe o repositório, Framework "Other", Deploy.
3. Cada `git push` na `main` publica de novo.
